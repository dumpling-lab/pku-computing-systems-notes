## 一、SMT 概述与动机

### 1.本讲需要抓住的总逻辑

SAT 只能处理命题逻辑（propositional logic）中的布尔变量，例如：

$$
(x_1\lor x_2\lor x_3)\land(\lnot x_1\lor\lnot x_2)\land(\lnot x_2\lor\lnot x_3)\land(\lnot x_3\lor\lnot x_1)
$$

其中每个变量只有真假两种取值。对于固定位宽程序示例，可以把运算展开成布尔电路，再转为 CNF，这称为 **bit-blasting**。展开可能使公式规模增大；不能据此认为任意整数、数组或带量词问题都能直接作有限的位级展开。

SMT（Satisfiability Modulo Theories，可满足性模理论）可以看成：

$$
\text{SMT} = \text{SAT 的布尔搜索框架} + \text{一阶逻辑表达能力} + \text{具体理论求解器}
$$

因此 SMT 能表达更复杂的约束，例如：

$$
f(x)=f(y)\land x+1=y\land load(a,i)=x\land x\&y=i
$$

这个概览示例展示不同理论的表达能力，并非可直接输入求解器的完整公式。实际编码必须明确变量类型，并保证算术、数组和位运算的类型一致。

本讲的重点不是 SMT 算法本身，而是 SMT 的逻辑基础：**First-Order Logic（一阶逻辑，FOL）** 和 **First-Order Theory（一阶理论）**。

------

### 2.SMT 总览

#### 2.1 SAT 和 SMT 的区别

SAT 的变量只有布尔值：

$$
x_i\in\{\top,\bot\}
$$

SAT 公式由布尔变量和逻辑连接词构成，例如 $\land,\lor,\lnot,\to,\leftrightarrow$。

SMT 在 SAT 的基础上引入：

1. **Domain（域）**：变量不一定只是布尔值，可以是整数、数组、位向量等。
2. **Function（函数）**：可以有 $f(x)$、$x+y$、$store(a,i,v)$ 等函数表达式。
3. **Predicate（谓词）**：可以有 $x<y$、$x=y$、$P(x)$ 等返回真假的表达式。
4. **Theory（理论）**：规定某类符号应该如何推理，例如整数加法、数组读写、位运算等。

常见 SMT 理论包括：

- **Theory of Equality**：等式理论，记为 $T_E$。
- **Equality with Uninterpreted Functions**：带未解释函数的等式理论，记为 $T_{EUF}$。
- **Linear Integer Arithmetic**：线性整数算术，记为 $T_{LIA}$。
- **Theory of Array**：数组理论，记为 $T_A$。
- **Theory of Bit-vector**：位向量理论，记为 $T_{BV}$。

可以粗略理解为：SAT 只知道布尔逻辑，而 SMT 还知道“整数加法是什么”“数组读写是什么”“固定宽度二进制数的异或是什么”。

------

#### 2.2 First-Order Logic 和 First-Order Theory 的关系

**First-Order Logic（一阶逻辑，FOL）** 是一个可扩展的逻辑框架。它规定了公式由哪些东西组成，比如变量、常量、函数、谓词、量词、逻辑连接词等。

**First-Order Theory（一阶理论）** 是在一阶逻辑框架下，对某个具体领域规定推理规则。例如：

- 在 $T_{LIA}$ 中，变量属于整数，加法就是整数加法，$<$ 就是整数大小关系。
- 在 $T_A$ 中，数组支持读取 `select` 和写入 `store`。
- 在 $T_{BV}$ 中，变量是固定宽度 bit-vector，异或、加法、溢出等按机器位宽解释。
- 在 $T_{EUF}$ 中，函数没有具体含义，但满足“相同输入得到相同输出”的一致性原则。

一阶逻辑提供“语法框架”，一阶理论提供“具体语义”。

### 3.SMT 的动机例子：程序等价性检查

下面用几个小程序说明为什么 SMT 比直接 SAT 更适合处理程序等价性问题。

核心思路是：要检查两个函数 `fun1` 和 `fun2` 是否等价，可以构造一个公式表示：

$$
\text{fun1 的输出} \ne \text{fun2 的输出}
$$

在编码准确表示原程序、两个程序使用相同输入且满足约定前提时，如果这个公式 **可满足（SAT）**，就给出输出不同的反例；若使用了未解释函数抽象，SAT 结果还需核对是否对应原程序的实际运算。

如果这个公式 **不可满足（UNSAT）**，说明不存在这样的输入，因此两个程序等价。

这个思想和前面 SAT 讲过的 **miter circuit（比较电路）** 是一致的：把两个设计放在一起，比较输出是否可能不同。

------

#### 3.1 例子一：临时变量交换与 EUF

**建模约定：** 以下三个程序按符号约束解释初始值。代码中未初始化的局部变量仅在该抽象模型中作为任意初值处理，不应直接运行或据此断言真实 C/C++ 程序的行为；乘法的数值范围也须另行约定。

程序如下：

```cpp
int fun1(int y) {
    int x, z;
    z = y;
    y = x;
    x = z;
    return x * x;
}

int fun2(int y) {
    return y * y;
}
```

为了表达程序执行过程，可以把每次赋值后的变量版本编号，例如 $y_0$ 表示初始输入，$z_1$ 表示执行 `z = y` 后的 $z$，$x_1$ 表示执行 `x = z` 后的 $x$。

若两个函数输出不同，则可以写出公式：

$$
z_1=y_0\land y_1=x_0\land x_1=z_1\land r_1=x_1\times x_1\land r_2=y_0\times y_0\land \lnot(r_2=r_1)
$$

其中：

- $r_1$ 是 `fun1` 的返回值。
- $r_2$ 是 `fun2` 的返回值。
- 最后一项 $\lnot(r_2=r_1)$ 表示两个输出不同。

以下是这个例子的一组 MiniSAT 实验记录，不能作为所有 SAT 求解器或所有问题的性能结论：

- 32-bit 的 $y$：超过 5 小时仍超时。
- 16-bit 的 $y$：约 37 秒。
- 8-bit 的 $y$：约 0.5 秒。

但是这里其实不需要真正理解乘法的所有位级细节。因为我们只需要知道：如果 $x_1=y_0$，那么 $x_1*x_1$ 和 $y_0*y_0$ 一定相等。于是可以把 $x*x$ 看成某个未解释函数 $sq(x)$，即：

$$
x\times x \quad \leadsto \quad sq(x)
$$

于是公式变成：

$$
z_1=y_0\land y_1=x_0\land x_1=z_1\land r_1=sq(x_1)\land r_2=sq(y_0)\land \lnot(r_2=r_1)
$$

结合 $z_1=y_0$ 和 $x_1=z_1$，可以推出：

$$
x_1=y_0
$$

在 $T_{EUF}$ 中，未解释函数满足一致性：

$$
a=b \Rightarrow f(a)=f(b)
$$

所以：

$$
sq(x_1)=sq(y_0)
$$

也就是 $r_1=r_2$，这与 $\lnot(r_2=r_1)$ 矛盾。因此公式 UNSAT，两个程序等价。对应实验中，EUF solver 约用 0.01 秒证明 UNSAT。

这里的关键点是：**EUF 不知道 $sq$ 真的是平方函数，但它知道同一个函数对相等输入必须给出相等输出。这个信息已经足够证明本例。**

#### 3.2 例子二：XOR 交换与 bit-vector 理论

程序如下：

```cpp
int fun1(int y) {
    int x;
    x = x ^ y;
    y = x ^ y;
    x = x ^ y;
    return x * x;
}

int fun2(int y) {
    return y * y;
}
```

这个例子包含按位异或 `^`。对应的公式可以写为：

$$
x_1=x_0\oplus y_0\land y_1=x_1\oplus y_0\land x_2=x_1\oplus y_1\land r_1=sq(x_2)\land r_2=sq(y_0)\land \lnot(r_2=r_1)
$$

这里仅靠 $T_{EUF}$ 不够，因为 EUF 不知道异或的性质，例如：

$$
(a\oplus b)\oplus b=a
$$

要推理这种按位运算，需要 **fixed-width bit-vector theory**，即 $T_{BV}$。bit-vector 理论把变量看成固定宽度的二进制向量，例如 8 位、16 位、32 位整数，并按照机器运算规则解释异或、加法、移位、溢出等操作。

这个例子的重点是：

- 如果公式只涉及“相等输入经过同一个函数得到相等输出”，EUF 可能就够了。
- 如果公式需要理解位运算，必须引入 $T_{BV}$。
- SMT 的优势在于可以组合不同理论：例如这里可以同时使用 $T_{BV}$ 和 $T_{EUF}$。

#### 3.3 例子三：数组读写与数组理论

程序如下：

```cpp
int fun1(int y) {
    int x[2];
    x[0] = y;
    y = x[1];
    x[1] = x[0];

    return x[1] * x[1];
}

int fun2(int y) {
    return y * y;
}
```

这个例子涉及数组读写。可以用数组理论中的两个基本操作表示：

- $select(a,i)$：读取数组 $a$ 的第 $i$ 个位置。
- $store(a,i,v)$：把数组 $a$ 的第 $i$ 个位置更新为 $v$，得到一个新数组。

对应的 SMT 公式可以写为：

$$
x_1=store(x_0,0,y_0)
$$

$$
y_1=select(x_1,1)
$$

$$
x_2=store(x_1,1,select(x_1,0))
$$

$$
r_1=sq(select(x_2,1))\land r_2=sq(y_0)\land \lnot(r_1=r_2)
$$

其中 $x_0,x_1,x_2$ 表示数组在不同程序点的版本。因为数组是可变对象，SMT 中通常用这种“函数式更新”的方式表示赋值后的新数组。

数组理论 $T_A$ 的核心语义可以概括为：

$$
select(store(a,i,v),i)=v
$$

如果读的是刚刚写入的位置，就读到新值。

并且当 $i\ne j$ 时：

$$
select(store(a,i,v),j)=select(a,j)
$$

如果读的是没有被这次写入影响的位置，就读到原数组的值。

在本例中，`x[0] = y` 后，`x[0]` 中保存的是 $y_0$；之后 `x[1] = x[0]`，所以最终 `x[1]` 也等于 $y_0$。因此 `fun1` 返回的平方和 `fun2` 返回的平方相同。

这个例子的重点是：**数组赋值不能只靠普通等式或 EUF 自然表达，需要数组理论来理解读写关系。**

## 二、一阶逻辑的语法

### 1.一阶逻辑 FOL：从命题逻辑扩展到更复杂对象

#### 1.1 命题逻辑和一阶逻辑的差别

命题逻辑（PL）只有布尔变量，例如 $p,q,r$。每个变量的含义就是真或假。

一阶逻辑（FOL）在命题逻辑基础上增加了：

1. **Domain（域）**：变量可以取某个集合中的元素，例如整数、数组、对象等。
2. **Function（函数）**：把域中的元素映射到域中的元素，例如 $x+2$、$f(x)$。
3. **Predicate（谓词）**：把域中的元素映射到真值，例如 $x<y$、$P(x)$。
4. **Quantifier（量词）**：可以表达“所有”和“存在”，即 $\forall$ 和 $\exists$。

命题逻辑中的变量本身就是真值；一阶逻辑中的变量通常是域中的对象，只有谓词表达式才是真值。

例如在一阶逻辑中：

- $x$ 是一个对象，不是布尔值。
- $x+2$ 是一个对象，不是布尔值。
- $x<y$ 是一个真假命题。
- $\exists y.\ x<y$ 是一个带量词的公式。

------

#### 1.2 FOL 的两个组成部分：语法和语义

一阶逻辑有两个层面：

**语法（syntax）** 规定公式由哪些符号组成，以及怎样组合才是合法公式。例如：

$$
\exists y.\ x<y\to \lnot(y<x)\lor (x+2=y+4)
$$

是否是合法公式，是一个语法问题。

**语义（semantics）** 规定这些符号是什么意思。例如：

- $+$ 是普通整数加法，还是模 2 加法？
- $<$ 是普通整数大小关系，还是某个自定义关系？
- 常量 $2$ 表示整数 2，还是在模 2 中表示 0？

同一个公式，在不同语义结构下可能有不同真值。

------

### 2.FOL 语法：公式由哪些符号组成

#### 2.1 一个线性整数算术的例子

以线性整数算术 $T_{LIA}$ 为例。假设唯一运算是加法，可以写出公式：

$$
\exists y.\ x<y\to \lnot(y<x)\lor (x+2=y+4)
$$

这个公式中包含：

- 变量符号：$x,y\in\mathcal X$
- 常量符号：$2,4\in\mathcal C$
- 函数符号：$+\in\mathcal F$
- 谓词符号：$=,<\in\mathcal P$
- 逻辑连接词：$\lnot,\lor,\to$
- 量词：$\exists$
- 辅助符号：点号、括号等

这里要特别注意：$+$ 是函数符号，因为它输入两个整数，输出一个整数；$<$ 和 $=$ 是谓词符号，因为它们输入对象，输出真假。

------

#### 2.2 FOL 的符号分类

一阶逻辑的符号可以分为以下几类。

**变量符号（variable symbols）**：

$$
x,y,z,\ldots\in\mathcal X
$$

变量符号在公式中表示待赋值的对象。

**常量符号（constant symbols）**：

$$
a,b,c,\ldots\in\mathcal C
$$

常量符号表示域中的某个固定元素。例如在线性整数算术中，$0,1,2,-1$ 都是常量符号。

**函数符号（function symbols）**：

$$
f,g,h,\ldots\in\mathcal F
$$

函数符号输入若干个域元素，输出一个域元素。例如 $+$ 可以看成二元函数。

**谓词符号（predicate symbols）**：

$$
P,Q,R,\ldots\in\mathcal P
$$

谓词符号输入若干个域元素，输出真值。例如 $<$、$=$、$P(x)$。

**逻辑符号（logical symbols）** 包括：

- 真值：$\top,\bot$
- 逻辑连接词：$\lnot,\lor,\land,\to,\leftrightarrow$
- 量词：$\forall$（for all）、$\exists$（there exists）
- 辅助符号：`.`、`(`、`)`

其中，常量符号、函数符号、谓词符号被称为 **非逻辑符号（non-logical symbols）**。这些符号的集合决定了某个逻辑语言能写出哪些合法公式。

------

#### 2.3 Arity：函数和谓词的参数个数

每个函数符号 $f$ 和谓词符号 $P$ 都有一个 **arity（元数）**，表示它需要几个参数。

记号：

$$
ar(f)=n
$$

表示函数 $f$ 是 $n$ 元函数。

$$
ar(P)=n
$$

表示谓词 $P$ 是 $n$ 元谓词。

例如：

- $+$ 是二元函数，$ar(+)=2$。
- $<$ 是二元谓词，$ar(<)=2$。
- $P(x)$ 中的 $P$ 如果只接收一个参数，就是一元谓词。
- 常量可以看成 0 元函数。

这个概念非常重要，因为一个公式是否合法，取决于你是否按照符号的 arity 正确使用它。

------

#### 2.4 Signature：签名

**Signature（签名）** 记为 $\Sigma$，表示一个逻辑语言中允许使用的非逻辑符号集合：

$$
\Sigma=\mathcal C\cup\mathcal F\cup\mathcal P
$$

其中：

- $\mathcal C$ 是常量符号集合。
- $\mathcal F$ 是函数符号集合。
- $\mathcal P$ 是谓词符号集合。

签名决定哪些公式是合法的。由签名 $\Sigma$ 定义出来的合法公式称为 **$\Sigma$-formula**。

例如，线性整数算术 $T_{LIA}$ 的非逻辑符号可以写为：

$$
\mathcal C=\{\ldots,-2,-1,0,1,2,\ldots\}
$$

$$
\mathcal F=\{+\}
$$

$$
\mathcal P=\{=,<\}
$$

若变量符号集合为：

$$
\mathcal X=\{x,y,z,\ldots\}
$$

则：

$$
x<x+y
$$

是合法的，因为只用了允许的变量、函数 $+$ 和谓词 $<$。

但是：

$$
2\times y<3+x
$$

不合法，因为这个签名里没有乘法符号 $\times$。

不过：

$$
y+y<3+x
$$

是合法的，因为它只使用了加法。

同理：

$$
x\times y=6
$$

也不合法，因为出现了不在签名中的乘法。

------

### 3.Term：项

#### 3.1 Term 的定义

**Term（项）** 是表示域中元素的表达式。也就是说，项的求值结果是某个对象，而不是真假。

项的构造规则是：

1. 单个变量符号是项。
2. 单个常量符号是项。
3. 如果 $f$ 是一个 $n$ 元函数，且 $t_1,\ldots,t_n$ 都是项，那么：

$$
f(t_1,t_2,\ldots,t_n)
$$

也是项。

这第三种也叫 **function expression（函数表达式）**。

------

#### 3.2 Term 的例子

以公式为例：

$$
\exists y.\ x<y\to \lnot(y<x)\lor (x+2=y+4)
$$

其中：

- $x,y$ 是项，因为变量是项。
- $2,4$ 是项，因为常量是项。
- $x+2$ 和 $y+4$ 是项，因为它们是函数表达式。

但：

$$
x<y
$$

不是项。因为 $x<y$ 的结果是真或假，它是谓词表达式，不是域中的元素。

一个很实用的判断方法是：

- 如果表达式表示“某个对象”，它通常是 term。
- 如果表达式表示“一个判断是否成立”，它通常是 formula。

例如：

- $x+1$ 是 term。
- $f(x)$ 是 term。
- $x+1<y$ 是 formula。
- $P(f(x))$ 是 formula。

------

### 4.Predicate Expression 和 Formula

#### 4.1 谓词表达式

如果 $P$ 是一个 $n$ 元谓词，且 $t_1,\ldots,t_n$ 都是项，那么：

$$
P(t_1,t_2,\ldots,t_n)
$$

是一个 **predicate expression（谓词表达式）**。

谓词表达式的求值结果是真值 $\top$ 或 $\bot$。

例如：

$$
x<y
$$

$$
x+2=y+4
$$

$$
P(f(x),a)
$$

都是谓词表达式。

------

#### 4.2 原子公式

一个谓词表达式就是一个 **atomic formula（原子公式）**。

例如：

$$
x<y
$$

$$
y<x
$$

$$
x+2=y+4
$$

都是原子公式。

它们已经是公式，但内部没有更小的逻辑连接词结构。

------

#### 4.3 公式的递归定义

公式可以递归构造：

1. 原子公式是公式。
2. 如果 $\phi,\psi$ 是公式，则下面这些也是公式：

$$
\lnot\phi
$$

$$
\phi\lor\psi
$$

$$
\phi\land\psi
$$

$$
\phi\to\psi
$$

$$
\phi\leftrightarrow\psi
$$

3. 如果 $\phi$ 是公式，则下面这些也是公式：

$$
\forall x.\phi
$$

$$
\exists x.\phi
$$

所以公式是表示真假值的表达式。

------

#### 4.4 公式例子拆解

考虑：

$$
\exists y.\ x<y\to \lnot(y<x)\lor (x+2=y+4)
$$

原子公式包括：

$$
x<y
$$

$$
y<x
$$

$$
x+2=y+4
$$

下面列举使用这些原子公式构成的非原子公式，不表示每一个都是上面整个公式的子公式：

$$
\lnot(y<x)
$$

$$
x<y\to \lnot(y<x)
$$

$$
x<y\to \lnot(y<x)\lor (x+2=y+4)
$$

$$
\exists y.\ x<y\to \lnot(y<x)\lor (x+2=y+4)
$$

实际书写时最好加括号避免歧义，例如写成：

$$
\exists y.\bigl((x<y)\to(\lnot(y<x)\lor(x+2=y+4))\bigr)
$$

------

### 5.Free Variable 和 Bound Variable

#### 5.1 自由变量和约束变量

应按变量的每一次出现及量词作用范围判断。位于相应量词作用范围内、被其绑定的出现是 **bound（约束的）**；未被绑定的出现是 **free（自由的）**。同一变量名在一个公式中可以有自由出现，也可以有约束出现。

例如：

$$
\phi:\ \exists x.\bigl(R(x,y)\land \forall z.P(z,x)\bigr)
$$

其中：

- 自由变量：$y$
- 约束变量：$x,z$

因为：

- $x$ 被最外层 $\exists x$ 绑定。
- $z$ 被 $\forall z$ 绑定。
- $y$ 没有任何量词绑定，所以是自由变量。

------

#### 5.2 Closed formula

如果一个公式不含任何自由变量，就称为 **closed formula（闭公式）**，也常称为 sentence。

例如：

$$
\forall x.\exists y.\ x<y
$$

这里 $x$ 和 $y$ 都被量词绑定，所以它是闭公式。

但：

$$
\exists y.\ x<y
$$

其中 $x$ 没有被绑定，所以不是闭公式。

自由变量为什么重要？因为有自由变量的公式要想判断真假，必须先给自由变量一个赋值。没有赋值时，它只是一个带参数的条件。

------

## 三、一阶逻辑的语义

### 1.FOL 语义：符号到底是什么意思

#### 1.1 为什么语法不够

语法只规定“能不能这样写”，但不规定“符号是什么意思”。

例如公式：

$$
x+1<2+y\lor(2=1)
$$

如果在普通整数中解释，$2$ 就是整数 2，$+$ 就是普通加法。

但如果在模 2 整数中解释，$2$ 和 $0$ 表示同一个元素，加法也是模 2 加法。

所以同一个语法公式，在不同语义结构下可能真假不同。

------

#### 1.2 FOL 语义的三个组成部分

要给一阶逻辑公式赋予语义，需要三个东西。

**1. Domain（域） $D$**

本讲采用非空域 $D$。域是变量、常量、函数值所在的集合。例如：

$$
D=\mathbb Z
$$

或者：

$$
D=\mathbb Z_2=\{0,1\}
$$

**2. Interpretation（解释） $I$**

解释 $I$ 规定非逻辑符号的含义：

- 常量符号映射到 $D$ 中的元素。
- 函数符号映射为真正的函数。
- 谓词符号映射为真正的关系或判断。

形式上，若 $f$ 是 $n$ 元函数，则：

$$
I(f):D^n\to D
$$

若 $P$ 是 $n$ 元谓词，则：

$$
I(P):D^n\to\{\top,\bot\}
$$

**3. Assignment（赋值） $s$**

赋值 $s$ 把变量映射到域中的元素：

$$
s:\mathcal X\to D
$$

例如：

$$
s(x)=0,\quad s(y)=1
$$

------

#### 1.3 Structure：结构

域 $D$ 和解释 $I$ 合在一起叫做一个 **structure（结构）**：

$$
M=\langle D,I\rangle
$$

结构是针对某个签名 $\Sigma$ 的。它告诉我们：

- 变量可以取哪些对象。
- 常量符号表示什么对象。
- 函数符号表示什么函数。
- 谓词符号表示什么关系。

赋值 $s$ 不属于结构本身，它负责给变量赋具体值。

------

### 2.Structure 的例子：普通整数算术与模 2 算术

#### 2.1 普通线性整数算术结构

考虑签名：

$$
\Sigma=\{\ldots,-1,0,1,\ldots,+,=,<\}
$$

普通线性整数算术可以定义结构：

$$
M=\langle D,I\rangle
$$

其中：

$$
D=\mathbb Z=\{\ldots,-2,-1,0,1,2,\ldots\}
$$

解释 $I$ 的作用是：

- 把常量符号 “$-1$” 映射为整数 $-1$。
- 把常量符号 “$0$” 映射为整数 $0$。
- 把常量符号 “$1$” 映射为整数 $1$。
- 把 $+$ 解释为普通整数加法。
- 把 $=$ 解释为普通相等关系。
- 把 $<$ 解释为普通小于关系。

这是我们最熟悉的整数语义。

------

#### 2.2 同一签名下的另一个结构：模 2 算术

同一个签名也可以给出不同结构：

$$
M'=\langle D',I'\rangle
$$

其中：

$$
D'=\mathbb Z_2=\{0,1\}
$$

解释 $I'$ 规定：

- 所有偶数常量符号，例如 $\ldots,-2,0,2,\ldots$，都映射到 $0$。
- 所有奇数常量符号，例如 $\ldots,-1,1,3,\ldots$，都映射到 $1$。
- $+$ 解释为模 2 加法。
- $=$ 仍解释为相等关系，例如 $0=0$、$1=1$ 为真。
- $<$ 解释为集合 $\{(0,1)\}$，也就是只有 $0<1$ 为真。

这个结构代表“模 2 的线性整数算术”。

关键点是：**签名相同不代表语义相同。签名只规定符号有哪些，结构才规定这些符号是什么意思。**

------

### 3.Evaluation：公式求值

#### 3.1 求值需要结构和赋值

给定一个 $\Sigma$-formula $F$，若有：

- 一个针对 $\Sigma$ 的结构 $M=\langle D,I\rangle$；
- 一个给自由变量赋值的 assignment $s$；

就可以在结构 $M$ 和赋值 $s$ 下计算 $F$ 的真值。

记号：

$$
M,s\models F
$$

表示公式 $F$ 在结构 $M$ 和赋值 $s$ 下为真。

若公式为假，则写作：

$$
M,s\not\models F
$$

------

#### 3.2 求值的步骤

对公式求值时，可以按照下面的顺序：

1. 用 assignment $s$ 给变量赋值。
2. 用 interpretation $I$ 解释常量、函数、谓词。
3. 先计算 term，例如 $x+1$、$2+y$。
4. 再计算 atomic formula，例如 $x+1<2+y$。
5. 最后计算逻辑连接词，例如 $\lor,\land,\lnot,\to$。
6. 如果有量词，还要根据 $\forall$ 或 $\exists$ 的语义处理；有限域可以枚举，无限域不能把枚举当成总能终止的算法。

可以把它理解为：先算对象，再算判断，最后算逻辑结构。

------

#### 3.3 例子一：普通整数结构下求值

考虑签名：

$$
\Sigma=\{\ldots,-1,0,1,\ldots,+,=,<\}
$$

公式：

$$
F: x+1<2+y\lor(2=1)
$$

使用普通线性整数算术结构 $M$，并给出赋值：

$$
s=\{x\mapsto 0,\ y\mapsto 1\}
$$

逐步求值：

$$
x+1<2+y\lor(2=1)
$$

代入变量：

$$
0+1<2+1\lor(2=1)
$$

解释常量后仍然是：

$$
0+1<2+1\lor(2=1)
$$

计算函数 $+$：

$$
1<3\lor(2=1)
$$

计算谓词 $<$ 和 $=$：

$$
\top\lor\bot
$$

计算逻辑连接词：

$$
\top
$$

所以：

$$
M,s\models F
$$

也就是 $M$ 在赋值 $s$ 下满足公式 $F$。

------

#### 3.4 例子二：模 2 结构下求值

仍然考虑同一个公式：

$$
F: x+1<2+y\lor(2=1)
$$

但这次使用模 2 结构：

$$
M'=\langle D',I'\rangle
$$

其中：

$$
D'=\mathbb Z_2=\{0,1\}
$$

赋值仍然是：

$$
s=\{x\mapsto 0,\ y\mapsto 1\}
$$

逐步求值：

$$
x+1<2+y\lor(2=1)
$$

代入变量：

$$
0+1<2+1\lor(2=1)
$$

在模 2 结构下，常量 $2$ 被解释为 $0$，所以：

$$
0+1<0+1\lor(0=1)
$$

计算模 2 加法：

$$
1<1\lor(0=1)
$$

在该结构中，只有 $0<1$ 为真，所以 $1<1$ 为假；同时 $0=1$ 也为假：

$$
\bot\lor\bot
$$

最终为：

$$
\bot
$$

所以：

$$
M',s\not\models F
$$

这个例子说明：**公式的语法没变，但结构变了，真值就可能改变。**

------

### 4.Quantifier：量词语义

#### 4.1 赋值的变体

$x$-variant of assignment 表示只改变变量 $x$ 取值的赋值变体。

若 $s$ 是一个赋值，记：

$$
s[x\mapsto a]
$$

表示一个新的赋值，它把变量 $x$ 映射到 $a$，而所有其他变量 $y$ 仍然保持原来的值：

$$
s[x\mapsto a](x)=a
$$

$$
s[x\mapsto a](y)=s(y)\quad (y\ne x)
$$

这个记号用于定义量词语义。

------

#### 4.2 全称量词 $\forall$

设结构：

$$
M=\langle D,I\rangle
$$

那么：

$$
M,s\models \forall x.\phi
$$

当且仅当：

$$
\text{for all }\alpha\in D,\quad M,s[x\mapsto\alpha]\models\phi
$$

也就是说，$\forall x.\phi$ 要为真，必须对域 $D$ 中每一个可能的 $x$ 值，$\phi$ 都为真。

------

#### 4.3 存在量词 $\exists$

同理：

$$
M,s\models \exists x.\phi
$$

当且仅当：

$$
\text{for some }\alpha\in D,\quad M,s[x\mapsto\alpha]\models\phi
$$

也就是说，$\exists x.\phi$ 要为真，只需要在域 $D$ 中找到一个值让 $\phi$ 为真。

------

#### 4.4 量词例子：在模 2 结构中求值

考虑签名：

$$
\Sigma=\{\ldots,-1,0,1,\ldots,+,=,<\}
$$

结构为模 2 结构：

$$
M'=\langle D',I'\rangle
$$

其中：

$$
D'=\mathbb Z_2=\{0,1\}
$$

要求值公式：

$$
F:\forall x.\exists y.\ x=y
$$

因为 $D'$ 只有两个元素，所以可以直接检查 $x=0$ 和 $x=1$ 两种情况。

当 $x=0$ 时，需要判断：

$$
\exists y.\ 0=y
$$

尝试 $y=0$，有：

$$
0=0
$$

为真，所以：

$$
\exists y.\ 0=y
$$

为真。

当 $x=1$ 时，需要判断：

$$
\exists y.\ 1=y
$$

尝试 $y=1$，有：

$$
1=1
$$

为真，所以：

$$
\exists y.\ 1=y
$$

为真。

两个 $x$ 的取值都能找到对应 $y$，因此：

$$
M'\models \forall x.\exists y.\ x=y
$$

这个例子本质上是在说：对每个元素 $x$，都可以选择 $y=x$。

------

## 四、有效性与可满足性

### 1.Validity、Satisfiability、Model

#### 1.1 $M,s\models\phi$ 和 $M\models\phi$

记号：

$$
M,s\models\phi
$$

表示在结构 $M$ 和赋值 $s$ 下，公式 $\phi$ 为真。

记号：

$$
M\models\phi
$$

表示对任意赋值 $s$，都有：

$$
M,s\models\phi
$$

这时称 $M$ 是 $\phi$ 的一个 **model（模型）**。

注意两者区别：

- $M,s\models\phi$：固定一个结构和一个赋值。
- $M\models\phi$：固定一个结构，但要求所有赋值都满足。

------

#### 1.2 Valid：有效

一个公式 $\phi$ 是 **valid（有效）** 的，当且仅当它在每个结构 $M$ 和每个赋值 $s$ 下都成立：

$$
\text{for every }M\text{ and }s,\quad M,s\models\phi
$$

在本节的术语约定下，有效公式也称 **tautology（重言式）**，记作：

$$
\models\phi
$$

直观理解：有效公式是“无论怎么解释符号、怎么给变量赋值都是真的公式”。

------

#### 1.3 Satisfiable：可满足

一个公式 $\phi$ 是 **satisfiable（可满足）** 的，当且仅当存在某个结构 $M$ 和某个赋值 $s$ 使它为真：

$$
\text{for some }M\text{ and }s,\quad M,s\models\phi
$$

直观理解：只要能找到一个世界、一个解释、一个变量赋值让公式成立，它就是可满足的。

------

#### 1.4 Unsatisfiable：不可满足

一个公式是 **unsatisfiable（不可满足）** 的，当且仅当不存在任何结构和赋值能让它为真。

也就是：

$$
\text{not satisfiable}
$$

------

#### 1.5 Refutable：可证伪

一个公式是 **refutable（可证伪）** 的，当且仅当它不是 valid。

也就是说，存在某个结构和赋值让它为假：

$$
\text{for some }M,s,\quad M,s\not\models\phi
$$

------

#### 1.6 四个概念之间的关系

可以用下面几句话记忆：

- Valid：所有结构、所有赋值都真。
- Satisfiable：至少一个结构、一个赋值为真。
- Unsatisfiable：没有任何结构和赋值为真。
- Refutable：至少一个结构、一个赋值为假。

因此：

- 在本讲通常的非空域语义下，Valid 一定 satisfiable。
- Unsatisfiable 一定不是 valid。
- Refutable 等价于 not valid。
- Unsatisfiable 等价于 not satisfiable。

做题时最实用的策略是：

- 证明 satisfiable：给出一个满足它的结构和赋值。
- 证明 not valid：给出一个反例结构和赋值。
- 证明 valid：对任意结构和赋值进行论证。
- 证明 unsatisfiable：说明所有结构和赋值都会导致矛盾。

------

### 2.例题：判断 SAT、UNSAT 或 Valid

#### 2.1 例题一：$(\exists x.P(x))\to P(y)$

考虑公式：

$$
(\exists x.P(x))\to P(y)
$$

问题：它是 SAT、UNSAT 还是 Valid？

结论：它是 **SAT，但不是 Valid**。

------

##### 证明它 SAT

我们只需要找一个结构和赋值让公式为真。

令结构：

$$
M=\langle D,I\rangle
$$

其中谓词 $P$ 对所有域中元素都为假：

$$
P(a)=\bot\quad \text{for all }a\in D
$$

于是：

$$
\exists x.P(x)
$$

为假，因为没有任何 $x$ 能让 $P(x)$ 为真。

所以整个公式：

$$
(\exists x.P(x))\to P(y)
$$

变成：

$$
\bot\to P(y)
$$

在经典逻辑中，假命题推出任意命题为真，因此公式为真。

所以它是 SAT。

------

##### 证明它不是 Valid

要证明不是 valid，需要找一个结构和赋值让公式为假。

令：

$$
D'=\{0,1\}
$$

并定义谓词 $P$：

$$
P(0)=\top,\quad P(1)=\bot
$$

再取赋值：

$$
s'(y)=1
$$

此时：

$$
\exists x.P(x)
$$

为真，因为可以取 $x=0$，使 $P(0)=\top$。

但：

$$
P(y)=P(1)=\bot
$$

所以整个公式为：

$$
\top\to\bot
$$

结果为假。

因此存在反例结构和赋值，公式不是 valid。

------

#### 2.2 例题二：$(\forall x.P(x))\to P(y)$

考虑公式：

$$
(\forall x.P(x))\to P(y)
$$

结论：它是 **Valid**。

证明时对任意结构 $M=\langle D,I\rangle$ 讨论。

**情况 1：存在某个域元素 $a\in D$ 使 $P(a)=\bot$。**

那么：

$$
\forall x.P(x)
$$

为假，因为并不是所有 $x$ 都满足 $P(x)$。

所以公式：

$$
(\forall x.P(x))\to P(y)
$$

的前件为假，整个蕴含式为真。

**情况 2：对所有域元素 $a\in D$ 都有 $P(a)=\top$。**

那么：

$$
\forall x.P(x)
$$

为真。

同时，无论赋值 $s$ 把 $y$ 映射到哪个域元素，都有：

$$
P(y)=\top
$$

所以公式变成：

$$
\top\to\top
$$

仍然为真。

两种情况都真，因此对任意结构和赋值，该公式都为真。所以：

$$
\models (\forall x.P(x))\to P(y)
$$

它是 valid。

这个例子体现了全称量词的基本推理：如果所有对象都满足 $P$，那么某个特定对象 $y$ 当然也满足 $P$。

------

## 五、可判定性

### 1.Decidability：可判定性

#### 1.1 什么叫 decidable

一个逻辑问题是 **decidable（可判定）** 的，意思是存在一个算法，对任意输入公式 $F$，总能在有限时间内停机并给出正确答案。

以有效性问题为例，如果存在算法满足：

- 当 $F$ valid 时，算法输出 “yes”；
- 当 $F$ not valid 时，算法输出 “no”；
- 对任意公式 $F$，算法总会停机；

那么这个有效性问题就是可判定的。

------

#### 1.2 一阶逻辑整体不可判定

**First-Order Logic is not decidable in general**。

也就是说，不存在一个通用算法，可以对任意一阶逻辑公式都判断它是否 valid 或 satisfiable，并保证总停机。

这和 SAT 不同。命题逻辑 SAT 虽然 NP-complete，但它是可判定的，因为变量个数有限时可以枚举真值表。FOL 引入了量词、无限域、函数等结构后，表达能力大幅增强，但也导致一般情形不可判定。

------

#### 1.3 为什么 SMT 仍然有用

虽然一般 FOL 不可判定，但某些一阶理论或一阶逻辑片段是可判定的。

例如很多 SMT 求解器常处理的是：

- quantifier-free EUF；
- quantifier-free bit-vector；
- linear integer arithmetic 的某些片段；
- array theory 的某些片段；
- 多理论组合下的可判定片段。

所以 SMT 的实际策略不是“求解任意 FOL”，而是把问题限制在工程上常见且可处理的理论和片段中。

这也是 SMT 能在程序验证、硬件验证、符号执行、编译器优化验证中发挥作用的原因。

------

## 六、概念整理

### 1.本讲核心概念对照

#### 1.1 语法层概念

- **Variable symbol**：变量符号，例如 $x,y,z$。
- **Constant symbol**：常量符号，例如 $0,1,2$。
- **Function symbol**：函数符号，例如 $+$、$f$、$store$。
- **Predicate symbol**：谓词符号，例如 $<$、$=$、$P$。
- **Arity**：符号需要的参数个数。
- **Signature $\Sigma$**：非逻辑符号集合 $\mathcal C\cup\mathcal F\cup\mathcal P$。
- **Term**：表示域中对象的表达式。
- **Atomic formula**：谓词表达式，是最基本的公式。
- **Formula**：表示真值的表达式，可以由原子公式、逻辑连接词和量词递归构造。
- **Free variable**：没有被量词绑定的变量。
- **Bound variable**：被量词绑定的变量。
- **Closed formula**：没有自由变量的公式。

------

#### 1.2 语义层概念

- **Domain $D$**：变量和项取值所在的集合。
- **Interpretation $I$**：解释非逻辑符号的含义。
- **Assignment $s$**：把变量映射到域中元素。
- **Structure $M=\langle D,I\rangle$**：域和解释的组合。
- **$M,s\models F$**：公式 $F$ 在结构 $M$ 和赋值 $s$ 下为真。
- **$M\models F$**：对所有赋值 $s$，都有 $M,s\models F$。
- **Model**：若 $M\models F$，则 $M$ 是 $F$ 的模型；赋值 $s$ 不属于结构 $M$ 本身。

------

#### 1.3 真值性质概念

- **Valid**：所有结构、所有赋值下都真。
- **Satisfiable**：存在某个结构、某个赋值使其为真。
- **Unsatisfiable**：不存在任何结构和赋值使其为真。
- **Refutable**：存在某个结构、某个赋值使其为假。
- **Decidable**：存在总能停机并给出正确 yes/no 答案的算法。

------
