# 计算系统建模、分析与优化｜课程学习笔记

北京大学梁云老师于 **2025—2026 学年春季学期**开设的“计算系统建模、分析与优化”（Modeling, Analysis, and Optimization for Computing Systems）课程学习笔记，旨在为后续学习者提供便于阅读、检索和复习的参考资料。

这是个人维护的非官方项目，不代表授课教师或北京大学。笔记可能存在疏漏，不能替代课程课件、课堂讲解与独立思考。
